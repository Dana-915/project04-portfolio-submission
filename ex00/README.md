# Project 04 — Personal Portfolio

## About the Project

This project is a personal portfolio created using HTML, CSS, and JavaScript. It demonstrates responsive web design, DOM manipulation, event handling, image switching, and internationalization.

## Project Structure

- `ex00/` — Personal portfolio with a theme switcher and contact form.
- `bounce01/` — Image switcher that changes between two images without reloading the page.
- `bounce02/` — Language switcher that translates the page between English and Arabic and changes the document direction.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

### Personal Portfolio
- About Me section
- Skills section
- Projects section
- Hobbies section
- Contact form demonstration
- Light and dark theme switcher
- Responsive layout

### Image Switcher
- Switches between two images.
- Updates the image source and alternative text using JavaScript.
- Uses a CSS transition for a smooth visual effect.

### Language Switcher
- Translates page content between English and Arabic.
- Uses a JavaScript translation dictionary.
- Updates the document language and direction.
- Supports left-to-right and right-to-left layouts.

## How to Run

Open the `index.html` file inside the folder you want to test using a web browser.

For example:
- `ex00/index.html`
- `bounce01/index.html`
- `bounce02/index.html`
